# Pull Request Template

Thank you for contributing to Historical Book AI Translator!

This project started with a simple idea: preserve historical knowledge, make forgotten books accessible again, and eventually build AI systems that can help us understand how people thought, learned, and discovered things throughout history.

Every improvement helps bring that vision closer to reality.

## Description of Changes

Please explain what your contribution does and why it is useful.

## Type of Contribution

Check all that apply:

- [ ] Bug fix
- [ ] New feature
- [ ] OCR or historical text recognition improvement
- [ ] Latin transcription correction
- [ ] Translation accuracy improvement
- [ ] Additional language support
- [ ] AMD Lemonade or local AI integration
- [ ] Performance optimization
- [ ] Documentation improvement
- [ ] Historical source or research contribution
- [ ] Other

## Testing Performed

Please describe how you tested your changes.

Include relevant information such as:

- Operating system and Python version
- AI backend and model used
- Sample historical documents tested
- Results before and after the changes
- Any errors or limitations encountered

## Historical Accuracy and Source Verification

For contributions involving historical material:

- [ ] Original source or publication information is provided
- [ ] Historical dates and authors have been checked
- [ ] Transcriptions have been compared against the original scans where possible
- [ ] Uncertain readings or translations are identified
- [ ] Historical interpretations are distinguished from modern explanations

## Compatibility

- [ ] Existing functionality remains operational
- [ ] No API keys, passwords, or personal credentials are included
- [ ] New dependencies are documented
- [ ] Changes are compatible with the project's current development direction

## Future Historical AI Development

If your contribution relates to future historical AI agents, please explain how it supports period-specific knowledge, historically grounded conversations, or future educational and VR experiences.

## Additional Notes

Include screenshots, examples, benchmark results, references, or other information that may help review your contribution.
